# Security policy

AgentShield AI is currently **pre-alpha / in design**. It has not been released as a security control and must not be relied on for production protection.

## Reporting vulnerabilities

**Do not publish live exploit details, secrets or private customer data in a public Issue.** Use GitHub's **Report a vulnerability** / private vulnerability reporting flow if it is enabled in the repository's Security tab.

If private reporting is not yet enabled, contact the maintainer through their GitHub profile to agree on a secure disclosure channel before sending sensitive details. Do not post a public proof of concept.

## Response and scope

Maintainer best-effort triage only; no formal response-time SLA has been established. Please include affected version/commit, impact, minimal reproduction using dummy data and recommended remediation if available.

## What we do not claim

- Production-grade prevention of prompt injection
- Formal OWASP/NIST certification or regulatory compliance
- Security of tools or workflows that bypass the gateway
- Assurance that blockchain anchored data was truthful at time of capture

Security review and test coverage will be updated as the implementation matures.
